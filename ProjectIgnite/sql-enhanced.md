## 主页面交互流程

### 核心工作流程：
```
1. 点击[连接数据库] → 弹出连接配置窗口 → 连接成功后更新状态栏
2. 在左侧编辑器输入原始存储过程
3. 点击[AI优化] → 弹出优化配置窗口 → 右侧显示优化后的SQL
4. 点击[执行对比] → 弹出参数配置窗口 → 主页面显示执行结果
5. 查看性能统计和数据对比结果
6. 点击相关按钮查看详细分析或导出报告
```

### 快捷操作：
- **双击结果数据行**: 查看详细数据
- **右键SQL编辑器**: 格式化、复制、查找替换等
- **Ctrl+点击性能指标**: 快速打开详细统计弹窗
- **拖拽文件**: 直接导入SQL文件

### 实时反馈：
- 连接状态实时显示在右上角
- SQL语法错误实时提示
- 执行进度实时显示
- 性能改进百分比动态更新

## Avalonia实现要点

### 主页面布局控件：
```xml
<Grid>
  <Grid.RowDefinitions>
    <RowDefinition Height="Auto"/>  <!-- 工具栏 -->
    <RowDefinition Height="2*"/>    <!-- SQL编辑区 -->
    <RowDefinition Height="1*"/>    <!-- 结果对比区 -->
    <RowDefinition Height="Auto"/>  <!-- 状态栏 -->
  </Grid.RowDefinitions>
</Grid>
```

### 弹窗管理：
```csharp
public class DialogService
{
    public async Task<bool> ShowConnectionDialog()
    public async Task<OptimizationConfig> ShowOptimizationDialog()
    public async Task<ExecutionParams> ShowExecutionDialog()
    public void ShowPerformanceDialog(PerformanceData data)
    public void ShowExecutionPlanDialog(ExecutionPlan original, ExecutionPlan optimized)
}
```

这样的单页面设计更加紧凑实用，所有核心功能一目了然，扩展功能通过弹窗提供详细配置，用户体验更加流畅！
